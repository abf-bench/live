# ABF live trace: Binance hot-wallet hack (2026-10-29)

Live site: https://abf-bench.github.io/live/

The ABF agent traces the stolen funds on Ethereum from the attacker's addresses. Every flow it records cites ledger records, and our verifier checks each one against the cited transaction before it is drawn as solid. This is agent output and has not been verified by human experts.

Paper: [ABF-Bench: A Verifiable Benchmark for Agentic Blockchain Forensics](https://arxiv.org/abs/2610.23656)
